# DIY-Thermocam Hardware

Open-source PCB, enclosure, and Bill of Materials files for DIY-Thermocam.

- **[PCB (`pcb/`)](pcb/README.md)** — KiCad 10 V4.0 zero-solder PCBA sources, Gerbers, BOM/CPL exports, and 3D STEP model (`pcb/fab/`). Proven V3.0 Eagle files live at git tag `3.0.4`.
- **[Enclosure (`enclosure/`)](enclosure/README.md)** — Parametric `build123d` CAD (`enclosure/cad/`), laser-cut and 3D/CNC exports (`enclosure/exports/`), and renders (`enclosure/renders/`).
- **[Bill of Materials (`bom/`)](bom/README.md)** — Single-source `bom.csv`, schema validator, and V3 → V4 prototype order guide.
