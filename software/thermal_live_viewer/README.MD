# DIY-Thermocam - Thermal Live Viewer

This Python application allows you to connect to your DIY-Thermocam from a PC over the USB serial protocol and stream live thermal images. Install the requirements with `pip install -r requirements.txt` (Python 3.12 works on Windows, Linux and macOS), run `python main.py` and pick the device's serial port from the list.

The Video Recording relies on FFMPEG and does currently only work under Windows.
