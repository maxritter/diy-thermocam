## Ordering & Fabrication Notes

- **FLIR Lepton sensor:** Both **Lepton 3.5** (`160×120`, recommended) and **Lepton 2.5** (`80×60`, optional budget fallback, EOL notice Sept 2027) fit the **Lepton Breakout Board V2.0**. Do not substitute PureThermal USB UVC boards — they lack the 2×10 SPI header.
- **PCB & Enclosure fabrication:** Order bare boards or V3.1 turnkey PCBA from **JLCPCB**, **Seeed Studio Fusion**, or **PCBWay** using the Gerber, Excellon, BOM, and CPL exports in [`hardware/pcb/`](https://github.com/maxritter/diy-thermocam/tree/master/hardware/pcb). Laser-cut 3 mm acrylic or 3D-print / CNC the shell from [`hardware/enclosure/`](https://github.com/maxritter/diy-thermocam/tree/master/hardware/enclosure).
- **Display options (BuyDisplay `ER-TFTM032-3`):** Select **Pin Header 4-Wire SPI**, **5V Power Supply**, **3.2-inch Resistive Touch Panel**, and **No Font Chip**.
- **Battery polarity:** Always verify JST-PH 2-pin polarity (`+` / `-`) against the PCB silkscreen before plugging in a LiPo cell.
